# Changelog

## 0.1.0 - 2026-10-30

- Independent action-review core and versioned task-authorization policy.
- DSH Auto component with inherit/fixed reviewer routing and bounded context.
- Exact action binding, source provenance, human approval and cancellation.
- Local metadata diagnostics and separate SDK/packaging checks.

The tested host is DSH 0.2.1-rc.3 on macOS. Other host versions are not admitted.
No real-model quality or latency benchmark is claimed for this release.
